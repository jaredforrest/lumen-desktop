# Dock file-offer acceptance

A separate private Wayland client advertises real `text/uri-list` data with automatic Copy dragging. Physical input carries that offer to the unchanged production Dock DropArea and the installed drop helper. A private registered application declares text support and records received local arguments, canonical URIs and file hashes. A mixed unsupported type must refuse the whole batch; a different incompatible receiver must not fall back to another application. A batch containing an inaccessible local path must fail before any partial application launch. Escape cancels the native offer and every source file remains unchanged.

This is a disposable local-protocol test, not authenticated application identity or an immutable external-handler handoff. The helper validates availability and declared MIME support before launching; an external handler may subsequently reopen a mutable path. No host registrations, default handlers, clipboard, accounts, network, input or personal files are used.

The fixture uses the accepted full namespace, source/dependency guard and explicit optional effects software-graphics capability. Its copied Dock source gains only read-only actual DropArea/worker observations with original/modified hashes and exact round-trip validation.

The separate offscreen preflight invokes the exact source QML typed IPC endpoint and checks its encoded URI-list byte length before any pointer input. It also runs the actual installed helper against the exact private observer, including GIO's permitted local-path argument form. Native setup cannot proceed on a textual IPC failure or empty source list.
