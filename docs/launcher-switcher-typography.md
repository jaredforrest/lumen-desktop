# Launcher and switcher text

Essential launcher search, category, result, preview and status text follows the shared text scale. Result rows, filters and footer use text metrics; filters and keyboard hints wrap within constrained widths. The result viewport takes the remaining actual window budget. Application icon sizes remain unchanged. Switcher captions use the shared label role and their card/strip grows only when needed. Tile width uses measured current/default glyph advances, with nominal text scaling as a floor, to preserve the original caption capacity despite font hinting while keeping the optical icons unchanged; the horizontal list keeps the selected tile in view.

The preview has focus-aware scrolling, with arrow/PageUp/PageDown/Home/End keyboard access. Its Open and Show Folder controls are actual keyboard/accessibility buttons. Pointer press and keyboard focus capture the result key; activation rejects a changed selection and still passes through the existing result-key/token validation. Existing query/history/result selection and launch dispatch remain unchanged.

The software fixture uses production AppLauncher in a private namespace with synthetic entries and no external activation. It covers list/grid/preview, normal/constrained windows, light/dark and 100/115/130/150% text, with 144 painted search/result/footer receipts and additional actual filter/metadata/body role metrics. Exact foreground ink is retained. Thin small glyphs at fractional origins can lack fully opaque pixels; the separate strong-ink guard permits at most 32 per-channel distance from the expected foreground (still far from these light/dark backgrounds), rather than changing typography to satisfy a raster assumption. The mask must occupy less than 60% of the text rectangle, rejecting a stale opposite-theme background that happens to match the expected foreground.

The Rust 2024 `launcher-typography` native scenario uses a private compositor, physical keyboard and pointer, and runs in both basic and effects variants. It checks enlarged list selection/Return, preview viewport End/Tab and Space, changed/removed key rejection, pointer click and held press with selection replacement, Tab to captured file Show Folder, and switcher selection/Escape/Return on normal/constrained light/dark outputs. It checks default and enlarged caption sizes and fixed icon size during live 100/115/130/150% scale changes, then navigates eight applications on the narrow output and commits the last captured application. It captures visible label pixels and checks backing-window activation and QML errors. No real application, filesystem open, account, clipboard history or host setting is exercised.

Long bounded text previews share this single viewport rather than nesting a clipped scroll area. The same Rust native scenario uses forty synthetic lines plus a final sentinel, proving arrow/page/home/end scrolling, final-line ink, Tab to captured actions and pointer wheel scrolling at constrained 150% in both appearance modes. The provider retains its existing content limits; no file is read by this fixture.
