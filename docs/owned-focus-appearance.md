# Owned key windows and visible focus

Files and Settings retain their selections when another window becomes key, using the inactive selection fill and readable text. Owned window controls follow their actual backing window's active state. The Files information utility retains its captured main-window/application context; it does not transfer the main selection to a different document.

`FocusOutline` is an inert two-pixel decoration using the primary text role. Unified window controls place it outside their existing circle; information section buttons place it inside their background. It changes no hit target, enabled state or action. A painted baseline demonstrated that the previous focused pixels never reached a 3:1 change contrast for these controls. The software fixture now requires at least four changed pixels at that engineering threshold, in light/dark with both transparency preferences. This is a focus visibility target, not a reference geometry measurement.

`owned_inactive_native.py` runs three separate production client processes (Files, Settings and Calendar), plus a Files-owned information utility, within one private application namespace. It cycles real key focus through all four windows under live palette/transparency updates, verifies captured PID/container ownership and retained selections, requires presented selection/control pixels, and sends a physical Tab to a distinct named control. Both unified and native decoration modes run on each supported compositor. The result's `capabilities` object explicitly limits the claim to the tested owned interfaces; it does not claim every shell surface or external application.

Fresh output and clean frozen source are required. Use the check workflow's pinned launcher, compositor, keyboard, software renderer and public font configuration arguments. All provider state and documents are disposable, buses are private and activation-free, and no host profile, device, account or desktop is used. Native acceptance remains separate from the software component focus corpus.
