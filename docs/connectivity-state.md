# Connectivity status

The shell reads existing local status on its normal controls refresh. It never initiates a connectivity check, enables checking, sends an Internet request or changes network ownership. Saved-network operations remain with the existing supplicant control interface.

Association is distinct from Internet reachability. Without an authoritative connectivity provider, a completed association displays “Internet status unknown”. NetworkManager observations are scoped to the supplicant interface; when that interface is absent, only a single unambiguous Wi-Fi device can supply status. Global connectivity, Ethernet and VPN state never establish Wi-Fi connectivity. The unique daemon owner is pinned across the snapshot and checked again before publication; both nonactivating daemon owner lookups and property/device calls share the same three-second read deadline. The Rust adapter establishes the local D-Bus connection. Missing or replaced owners discard its facts.

Device states distinguish disabled, disconnected, association, address acquisition, connected, disconnecting and unavailable. Per-device IPv4/IPv6 connectivity produces full, captive portal, limited or no Internet labels only when existing checking is enabled and available. A successful family wins over a limited family; an unknown family prevents a no-Internet conclusion from the other family's absent route. Labels describe the backend's latest observation, not a continuing guarantee. A missing control socket means controls unavailable, not proof of absent physical hardware. Status loss clears previous connectivity, and no action is retried.

The adapter uses the [NetworkManager device properties](https://networkmanager.dev/docs/api/latest/gdbus-org.freedesktop.NetworkManager.Device.html) and [connectivity state definitions](https://networkmanager.dev/docs/api/latest/nm-dbus-types.html). It reads properties only; it never calls `CheckConnectivity`, modifies radio properties, opens a captive portal or obtains network credentials.

Tests include a pure state matrix, Rust 2024 activation-free private D-Bus transitions/owner loss/replacement, and real Qt tile/details label updates using synthetic states. These do not change the host network or use account providers. The native fixture is available as `.#test-network-connectivity-provider-fixture`; pass `--client` with the binary from `.#network-connectivity` and a fresh `--output` directory.
